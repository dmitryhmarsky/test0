# Сторонние компоненты

Установщик Instant Replay включает следующие компоненты с открытым исходным кодом.
Они распространяются под своими лицензиями и **не подписываются** сертификатом Instant Replay.

| Компонент | Лицензия | Исходный код |
|---|---|---|
| FFmpeg (`ffmpeg.exe`, сборка BtbN, GPL) | GPL-3.0-or-later | https://github.com/FFmpeg/FFmpeg, https://github.com/BtbN/FFmpeg-Builds |
| Python | PSF License | https://github.com/python/cpython |
| CustomTkinter | MIT | https://github.com/TomSchimansky/CustomTkinter |
| keyboard | MIT | https://github.com/boppreh/keyboard |
| pystray | LGPL-3.0 | https://github.com/moses-palmer/pystray |
| Pillow | MIT-CMU (HPND) | https://github.com/python-pillow/Pillow |
| PyAudioWPatch | MIT | https://github.com/s0d3s/PyAudioWPatch |
| PyInstaller (загрузчик) | GPL-2.0 с исключением для загрузчика | https://github.com/pyinstaller/pyinstaller |
