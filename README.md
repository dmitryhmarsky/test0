# InstantReplay — мгновенный повтор для Windows

Работает как «Мгновенный повтор» в NVIDIA GeForce Experience / ShadowPlay: программа всё время пишет экран в фоне,
а по горячей клавише сохраняет последние N секунд в MP4.

- 2560×1440 (2K), 30 fps, H.264
- аппаратное кодирование: NVIDIA NVENC → AMD AMF → Intel QuickSync, если их нет — libx264 (процессор)
- захват через Desktop Duplication API (`ddagrab`), он почти не нагружает систему
- буфер хранится на диске (кольцо из 2-секундных сегментов), поэтому оперативной памяти нужно мало
- ролик сохраняется меньше чем за секунду: без перекодирования, сегменты просто склеиваются
- иконка в трее: сохранить, пауза, открыть папку, выход

## Запуск

1. Скачайте ffmpeg 6.0 или новее: https://www.gyan.dev/ffmpeg/builds/ (`ffmpeg-release-full.7z`), положите `ffmpeg.exe` рядом с программой.
2. Вариант A — из исходников: `pip install -r requirements.txt`, затем `python instant_replay.py`
   Вариант B — exe: запустите `build.bat`, получите `dist\InstantReplay.exe`.
3. **Alt+F10** — сохранить повтор, **Alt+Shift+F10** — пауза.
   Ролики сохраняются в `Видео\InstantReplay`.

## Настройки (`config.json`, создаётся при первом запуске)

| Параметр | По умолчанию | Описание |
|---|---|---|
| `hotkey` | `alt+f10` | горячая клавиша сохранения |
| `replay_seconds` | `60` | длина повтора в секундах |
| `width`/`height`/`fps` | `2560`/`1440`/`30` | разрешение и частота кадров |
| `bitrate` | `20M` | битрейт видео |
| `encoder` | `auto` | `h264_nvenc`, `h264_amf`, `h264_qsv`, `libx264` |
| `monitor` | `0` | номер монитора |
| `audio_device` | `""` | звук системы через DirectShow, например `"Stereo Mix (Realtek(R) Audio)"` |
| `mic_device` | `""` | микрофон (смешивается со звуком системы) |

Чтобы узнать имена аудиоустройств: `ffmpeg -list_devices true -f dshow -i dummy`.
Если нужен звук системы, а «Стерео микшера» нет — включите его в панели звука Windows
или поставьте [virtual-audio-capturer](https://github.com/rdp/screen-capture-recorder-to-video-windows-free).

## Ограничения

- Игры в эксклюзивном полноэкранном режиме лучше запускать в режиме «Окно без рамки».
- Если игра запущена от администратора, программу тоже нужно запустить от администратора, иначе горячая клавиша не сработает.
- Лог ffmpeg: `%TEMP%\InstantReplay\ffmpeg.log`.
