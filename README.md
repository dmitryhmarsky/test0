# Instant Replay — мгновенный повтор для Windows

Работает как «Мгновенный повтор» в NVIDIA GeForce Experience / ShadowPlay: программа всё время пишет экран в фоне,
а по горячей клавише сохраняет последние N секунд в MP4.

## Возможности

- **Окно в современном стиле** (тёмная/светлая тема): главная, галерея повторов, настройки видео, звука, горячих клавиш
- **Трей и автозагрузка**: стартует вместе с Windows, свёрнутая в трей, и сразу начинает запись
- **Видео**: 720p / 1080p / 2K, 30 / 60 FPS, H.264, битрейт «Авто» или вручную, выбор монитора
- **Длительность повтора**: от 15 секунд до 20 минут
- **Звук системы** через WASAPI loopback (без «Стерео микшера»), с регулировкой громкости в видео (0–200 %)
- **Микрофон**: выбор устройства, громкость и усиление (до +30 дБ); смешивается со звуком системы, есть лимитер против перегруза
- **Горячие клавиши** можно переназначить:
  | Действие | По умолчанию |
  |---|---|
  | Сохранить повтор | Alt + F10 |
  | Пауза / продолжить | Alt + Shift + F10 |
  | Открыть окно программы | Alt + F9 |
  | Галерея повторов | Alt + F11 |
- **Галерея**: превью, длительность, размер; можно открыть ролик, показать в папке или удалить
- Аппаратное кодирование: NVIDIA NVENC → AMD AMF → Intel QuickSync → процессор (x264)
- Буфер лежит на диске в `%TEMP%` (сегменты по 2 с), оперативной памяти нужно мало; повтор сохраняется за долю секунды, без перекодирования

## Установка

1. Установите [Python 3.10+](https://www.python.org/downloads/) (с галочками «tcl/tk» и «Add to PATH»).
2. Скачайте [ffmpeg 6.0+](https://www.gyan.dev/ffmpeg/builds/) (`ffmpeg-release-full.7z`) и положите `ffmpeg.exe` в папку с программой.
3. Запустите `run.bat`. Если нужен один exe-файл — запустите `build.bat`, результат появится в `dist\InstantReplay.exe`.

Настройки хранятся в `%APPDATA%\InstantReplay\config.json`, ролики сохраняются в `Видео\InstantReplay`.

## Советы

- Игры в эксклюзивном полноэкранном режиме лучше запускать в режиме «Окно без рамки».
- Если игра запущена от администратора, программу тоже нужно запустить от администратора, иначе горячие клавиши не сработают.
- Если запись не запускается, откройте «Общие → Журнал ffmpeg».
- Изменение разрешения, FPS или источников звука перезапускает буфер; громкость меняется без потери буфера.
